# Round 7 fixes, area S

| id | verdict | what changed or why |
|----|---------|---------------------|
| S-1 | fixed | `directory()` now scans the whole file for an end record when the 64 KB window has none (JSZip does), refuses one found far away, and refuses a `PK`-start file with no directory. On top of that the cap is enforced while inflating (see S-2 note). Test: junk byte + zip + 70 000 trailing bytes. |
| S-2 | fixed | Pre-filter refuses an entry with two ZIP64 extra fields, one with no marker, or a marker with none. Real fix is structural: `zipTooBig` now inflates every part through JSZip's `internalStream` (`readCapped`), counting output and stopping past the part and total caps, and refuses a zip JSZip cannot read (SheetJS is more lenient). The old DecompressionStream count is gone. PowerPoint reads every part through `openCapped` (no uncapped `.async()` anywhere). Word (docx-preview uses the same JSZip) and the xlsx worker (SheetJS) go through `zipTooBig`, so layout filter plus capped total hold before either parser runs. Tests: capped reader and shared budget, plus real docx/xlsx/pptx files that still pass. |
| S-3 | fixed | Template checker now uses an allow-list for `${…}` (name, `#name`, `name[@]`/`[*]`, `:-` `:=` `:+` `:?`, `%`, `%%`, `#`, `##`, `/`, `//`); refuses `${!…}`, substring offsets, zsh flags, any other subscript (also `$a[…]`, `${a}[…]`, `a[n]=`), nested `${…${`. Refuses `read`, `unset`, `trap`, `mapfile`/`readarray`, `compgen`/`complete`/`vared`/`repeat`, `declare/typeset/local/export/readonly -n/-i/-F/-E`, `printf -v`, `-v`/`-R` tests, `exit/shift/…` with a variable. Words are checked after stripping quotes/backslashes (`r""ead`) and `=` splits words (`r=read`). Rust and TS mirrored; every S.md row is a shared vector, and several run for real in bash in `round5_refusals_really_run_names`. |
| S-4 | fixed | `trap` is refused anywhere, `PS4`/`PROMPT_COMMAND`/`BASH_ENV` are refused as names anywhere. Real-shell test for `trap "echo $n" EXIT` and `PS4=$n`. |
| S-5 | partly fixed | `"${files[@]}"`, `${files[*]}`, `${#files[@]}` and the other allowed `${…}` forms now pass. Arithmetic (`i=$((i+1))`), `-gt`-style tests and `read` stay refused on purpose (the price of safety, the messages say why). |
| S-6 | fixed | `redact` matches credential words inside any name (`secret_key`, `AccountKey=` incl. Azure strings, `aws_secret_access_key = `, `X-Amz-Security-Token:`, `?auth_token=`…) with name length capped at 40 each side so a long word stays linear; `Authorization:` hides the whole line. Tests added. Plain words like `design=` stay. |

Known gaps (user's own template, not catchable by syntax): a command name built from an allowed expansion (`${e}al`), `sh -c '…'` re-reading arguments.
