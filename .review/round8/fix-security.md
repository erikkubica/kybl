# Round 8, area S (security): triage

| id | verdict | what changed or why |
|---|---|---|
| S-1 | fixed | `src/viewers/zipCheck.ts`: new `plainForSheetJS`. Every part is read through the capped JSZip reader (one shared budget), then a fresh zip is written with JSZip from exactly those bytes (STORE, true sizes, no data descriptor, no comment, no extras, one entry per name, no directory entries). Only that zip goes to SheetJS (`xlsx.worker.ts`); this covers .xlsx and .ods (the only SheetJS entry point is the worker). Not a zip (old .xls = compound file, CSV): passed on as is; a compound file has no compression, so what SheetJS reads is bounded by the file itself, already capped at 30 MB by the registry (no extra cap added there). Tests in `tests/viewers/zipCheck.test.ts`: the 0-size entry, the directory-flag entries (name and DOS attribute) and the data-descriptor entry are built by hand; each is refused or rebuilt plain and small. Also a real xlsx/ods round trip. |
| S-2 | fixed | Rust and TS `evaluation_problem`: any expansion (`$`, backtick, `(`) in the NAME of `declare`/`typeset`/`export`/`local`/`readonly`/`integer` is refused (flags skipped, text before `=` is the name; `x="$v"` stays fine). `unset` was already refused outright. The command word is found after keywords, `NAME=value` prefixes and `f() {`. Vectors added; real-shell test `round8_refusals_really_run_names` runs zsh and bash 3.2 cases. |
| S-3 | fixed | Assignment (by `X=`, `export X=`, `declare X=`, `for X in`) to OPTIND, OPTARG, RANDOM, SECONDS, TMOUT, LINENO, SHLVL, MAILCHECK, ENV, BASH_ENV, PS4, PROMPT_COMMAND, IFS, PATH is refused. ksh `shift` / `ulimit` with any operand that is not a number, `$?`/`$#`/`$$` or a flag is refused. An expansion (`$` or backtick) in the word after `>&` / `<&` is refused. All mirrored in Rust and TS, with vectors and real-shell rows (ksh, bash 3.2, sh). |
| S-4 | fixed | `src/logText.ts`: quoted values run to the matching quote (also `\"` JSON inside a string, and an unclosed quote to the end of the line); bare values run to whitespace (only in a URL query does `&` end one); the name scan starts at the credential word (no 40-character prefix limit; 80 after it); added `pass pw pswd sid jwt otp key session authkey` (whole names only, so `monkey`/`hotplug` stay) and `credential`, `auth_key`, `session_id/key` inside names; `--password x`, `-pass x` and FTP `PASS x`; PEM markers in any case. Not done on purpose: `user:p/ss@host` (a `/` in a URL password; a bare `@` rule would hide ordinary paths), `user:pass@host` without a scheme, key bodies that lost their BEGIN line. Linear on 200 000-character inputs (all under 100 ms). |
| S-5 | fixed | `src/activityLog.ts`: split on line breaks, trim each piece, drop empty ones, join with one space (same result, linear); the sentence is also cut at 4000 characters first. Test with 200 000 blanks. |
