Kybl manual

How to use every part of Kybl

Kybl is one file manager for your buckets, cloud drives, servers and your own disk. This manual walks through everything it does, task by task, on your computer and on your phone.

Add a connection Split panes Copy between connections Sync a folder Mirror a site Shortcuts Troubleshooting

Shortcuts in this manual are written for the Mac. On Windows and Linux, press Ctrl where you see ⌘ and Alt where you see ⌥. ⇧ is Shift and ⌃ is Control on every system. "This computer" means the built-in connection to your own disk; the app calls it This Mac or This PC.

Getting started

Kybl is free. It runs on macOS (Apple Silicon and Intel), Windows, Linux, Android and iPhone or iPad. Get it from the download section on the homepage.

Install on macOS

  1. Download the build for your Mac: Apple Silicon (M1 and newer) or Intel.
  2. Open the download and drag Kybl into your Applications folder.
  3. Open Kybl. The first time, macOS may say it can't check the app. Open System Settings → Privacy & Security, scroll down and click Open Anyway.

Updates keep the same signature, so macOS won't ask again.

Install on Windows

  1. Download the 64-bit installer and run it.
  2. If Windows SmartScreen warns you, click More info, then Run anyway.
  3. Start Kybl from the Start menu.

Install on Linux

Pick the AppImage (it updates itself), or the .deb or .rpm package for your distribution. Make the AppImage executable and run it, or install the package as usual.

Kybl keeps your passwords and keys locked with a key stored in your system keyring. On Linux that needs a Secret Service, such as GNOME Keyring or KWallet. Most desktops already have one.

Install on iPhone and iPad

The iPhone app isn't in the App Store, so you install it yourself ("sideloading"). It needs iOS 15 or newer.

  1. Install AltStore or SideStore on your iPhone.
  2. Add the Kybl source. On the homepage, tap Add to AltStore or SideStore, or add this source address by hand:
    https://github.com/erikkubica/kybl/releases/latest/download/altstore-source.json
  3. Install Kybl from the source. New versions then show up as updates in AltStore or SideStore.

You can also install the Kybl.ipa file with Sideloadly. A free Apple ID signs apps for 7 days; AltStore and SideStore renew them on their own.

Install on Android

  1. On your phone, download Kybl.apk (Android 7 or newer).
  2. Open it. When the phone asks, allow your browser to install apps.
  3. Later versions install over the old one, keeping your connections.

First launch

With no connections yet, Kybl shows a welcome card with two ways in:

  • Connect Kybl Storage gives you 10 GB of free storage in the EU, with no keys to type. See Kybl Storage.
  • Add another S3 connection with keys, or New connection at the bottom of the sidebar, connects your own storage or server. See Connections.

Kybl remembers where you were. Next time it reopens each pane at its last folder (you can turn this off in Settings → General).

A tour of the window

Sidebar
Your favorites, This computer's folders and your connections. Connections with buckets or drives fold open to show them. The bottom has New connection, a terminal button, the folder-sync status and Settings. Fold it away with ⌥⌘S; see The sidebar.
Workspace tabs
The strip along the top. Each tab is a saved layout of panes, like browser tabs. See Workspaces.
Panes
Each pane shows one folder on one connection, or a terminal. You can have up to six. See Panes.
Pane toolbar
At the top of each pane: the connection button, the path (breadcrumbs), the … menu (refresh, Go to folder, Add to favorites, the other pane and more), Upload or create, Sort and group, Filter or search, Terminal and the Panes button. You can drag a pane by the empty part of its toolbar.
Status bar
Under each pane: how many items and how big, what you've selected, and the size of the whole folder once Kybl has added it up. At its right end are the list, grid and compact buttons, and an icon that opens the folder info panel.
Activity panel
At the bottom of the window. It lists uploads, downloads, copy jobs and a plain-language log. See Transfers and activity.

The sidebar

  • The sidebar has four parts: Favorites, This computer (its folders: Home, Documents and so on), Groups and Connections (the ones in no group). Click a heading to fold it shut; each has a sort menu.
  • Favorites are folders and roots you added with Add to favorites. Click one to open it; hover and click × to remove it. A favorite whose connection is gone turns grey.
  • Connections lists everything you added. S3 buckets and cloud-drive roots show under their connection. A server with one root (FTP, SFTP, WebDAV) is a single row. You can file connections into your own groups.
  • Your recent places are in the command palette. A new, empty pane lists your recent connections.
  • Find connection appears at the top when you have more than eight connections; press ⌥⌘F to show it any time. It searches names, servers, user names, kinds and groups. Arrow keys and ↵ open a result.
  • Right-click a bucket to Hide from the sidebar (a row such as "2 hidden" under the connection lets you bring it back with the eye icon), to Add to favorites, or to use Copy / Move to….

Folded sidebar. Folding hides the sidebar completely; only its button stays, next to the window controls. Press ⌥⌘F and the full sidebar slides in over the panes so you can find a connection; it goes away when you pick something or move the pointer off it. Kybl never folds or unfolds the sidebar on its own.

Closing and quitting

  • Closing the window keeps Kybl running in the menu bar (macOS) or the system tray (Windows, Linux), so folder sync, jobs and drives keep working. Turn this off in Settings → General with Keep running in the menu bar.
  • To quit, choose Quit Kybl from the tray icon, or, on a Mac, press ⌘Q. If transfers are running or the editor has unsaved changes, Kybl asks first. Quitting stops transfers, cleans up unfinished uploads and removes partial downloads.
  • Open at login starts Kybl quietly in the tray, so synced folders stay current.

Windows and Linux have no menu bar at the top of the window. Every menu command is still there, from the keyboard, the right-click menus and the command palette (⌘K).

Getting help

  • Press F1 on any system to open this manual in your browser. On macOS, ⇧⌘/ does the same.
  • On macOS the Help menu has Kybl Manual, Keyboard Shortcuts, What's New in Kybl and Report a Problem…. The command palette has the same four commands, so they work on Windows and Linux too.
  • Keyboard Shortcuts opens the list in Settings. What's New opens the release notes and Report a Problem opens a new issue on GitHub (see Reporting a problem).
  • In Settings, each page has a Help button in its header that opens that page of the manual. The sidebar's Help group has Keyboard shortcuts and the links User manual, What's new and Report a problem.
  • Many dialogs have a ? in their title row. It opens the matching section of the manual.

Connections

A connection is one storage account or server: an S3 bucket provider, a cloud drive, an FTP server and so on. Add as many as you like.

Add a connection

  1. Click New connection at the bottom of the sidebar (or choose it from the command palette).
  2. Pick a kind. They come in three groups: Cloud drives (Google Drive, OneDrive, Dropbox), Object storage (Kybl Storage, S3 Compatible, Azure Blob Storage, Google Cloud Storage) and Servers (WebDAV, SSH, SFTP, FTP / FTPS).
  3. Fill in the form. The name is optional; Kybl makes one up, such as "alice@files.example.com".
  4. Click Test connection to check it, then Save.

Every form also has a Group field (see Groups) and a Photos in lists choice, which overrides the thumbnail setting for that connection.

Test connection really connects, signs in and opens the start folder, so the message you see is the real problem, if any.

  • Bucket: the connection opens straight into it. You need this when your key can't list buckets.
  • Endpoint: must start with https:// or http://. Required for everything except Amazon S3.
  • Use path-style addressing: needed by MinIO and many self-hosted servers.

If your key can't list buckets and you didn't set one, the pane offers Open bucket by name. You can also find it in the connection's list of buckets in the sidebar.

Azure Blob Storage

Enter the Storage account, the Container (one container per connection) and either the Account key or a SAS token. Leave Endpoint empty unless you use Azurite or a national cloud.

Google Cloud Storage

Enter the Bucket and paste the Service account key (the JSON file from Google Cloud), or click Choose file…. The Endpoint field is only for emulators and compatible services.

Google Drive, OneDrive and Dropbox

  1. Choose the drive in the picker and click Sign in with Google (or Microsoft, or Dropbox).
  2. Your browser opens the provider's sign-in page. Sign in and allow Kybl.
  3. Back in Kybl, the connection saves itself. There are no keys to type.
  • Google Drive shows My Drive, each shared drive, and Shared with me (read-only at its top). Google Docs, Sheets and Slides download as Office files or PDF.
  • OneDrive shows your OneDrive and a read-only Shared with me.
  • Dropbox shows one root.
  • Deleting on any of them goes to that service's trash, so you can restore it there.
  • Advanced: Use your own app (advanced) lets you enter your own client ID (and secret for Google, tenant for OneDrive).

If your access ends (you changed your password, or revoked Kybl), the sidebar shows Sign in again. Signing in again keeps the same connection, so your favorites, synced folders and jobs stay attached.

WebDAV (Nextcloud, ownCloud, Synology…)

Enter the Server address, and a User name and Password if the server needs them. Start in folder is optional.

  • Nextcloud and ownCloud: the server address alone is enough; Kybl finds your files folder.
  • Synology: include the WebDAV port, for example https://nas.local:5006.
  • If your account uses two-step sign-in, create an app password and use that.

An http:// address means your password and files travel unencrypted. Use https:// when the server supports it.

SSH and SFTP servers

Enter the Server, the User name and the Port (empty means 22). You can paste sftp://me@host:2222 into Server and Kybl fills in the rest. Then choose how to sign in:

  • Password (it also answers "keyboard-interactive" prompts).
  • Key: paste a private key or click Choose file…. OpenSSH, PEM and PuTTY .ppk keys work (Ed25519, ECDSA, RSA). Add the passphrase if the key has one.
  • SSH agent (computers only): uses the agent you already run, such as ssh-agent, Pageant, Windows' OpenSSH agent or 1Password. Nothing is stored in Kybl.

Start in folder is optional; empty means your home folder.

Trust on first use. The first time you connect, Kybl shows the server's fingerprint and asks Trust this server? If the server's key changes later, Kybl stops and warns you, because someone might be in the middle. You can check the new key and replace the old one with a deliberate click. The trusted fingerprint is shown in the form with a Forget button.

SFTP connections also give you a terminal on the server, SSH tunnels, permissions, symbolic links, search inside files and custom actions that run on the server.

FTP and FTPS servers

Enter the Server (you can type host:port), and choose the Encryption:

  • FTPS (explicit TLS) (port 21): the usual choice, and the default.
  • FTPS if available: like FileZilla's "TLS if available". Kybl asks you once before it sends a password unencrypted.
  • FTPS, implicit TLS (port 990): for older servers.
  • None (plain FTP): plain FTP. Your password and files cross the network readable, so Kybl warns you.

If a server doesn't offer encryption, the error has a Connect without encryption button. Kybl never drops encryption for a server that has used it before. Leave User name empty to sign in anonymously.

This computer

Your own disk is always there as This Mac or This PC (on phones, On this phone). You don't add it. Its folders show in the sidebar, deleting goes to the Trash or Recycle Bin, and files open in their own apps. Hidden files (dot-files) are hidden until you show them.

Certificates and trust

If an FTPS or WebDAV server uses its own (self-signed) certificate, the connection fails with Trust this certificate…. Click it to see why, in plain words, plus who it's made out to, who issued it, when it expires and its fingerprint. Trust it only if you expect it. If the certificate later changes, not connecting is the default. The trusted certificate is shown in the form with Forget.

Import from FileZilla and other apps

  1. Choose Import connections… in the New connection picker, or in Settings → Connections.
  2. Pick a source Kybl found on your computer, or choose a file. Kybl reads FileZilla's Site Manager (and its exports) and your SSH config (~/.ssh/config).
  3. Tick the sites to bring in. Sites you already have, and ones Kybl can't open (with the reason), start unticked. Each row says how it signs in and what doesn't carry over.
  4. Click import. Saved passwords and key files go straight into Kybl's encrypted store.
  • FileZilla folders become sidebar groups.
  • Each SSH config host becomes an SFTP connection in an "SSH config" group, and its LocalForward lines become SSH tunnels. ProxyJump and ProxyCommand aren't supported.
  • FileZilla passwords protected with a master password can't be read; enter those by hand.

The command palette has Import Connections… too. The sources Kybl reads are FileZilla and SSH config files.

Edit or delete a connection

  • Right-click the connection in the sidebar and choose Edit connection…, or click Edit next to it in Settings → Connections.
  • Leaving a password or secret empty keeps the saved one. If you change the server, user name or access key, Kybl asks for the secret again, so a saved password is never sent somewhere new.
  • Delete in the dialog removes the connection and its stored passwords, keys and sign-ins.

Groups, pins and favorites

  • Groups are folders in the sidebar. Type a group in the connection's Group field; use / for nested groups, like Clients/Acme. Or right-click a connection and choose Move to group ▸.
  • To file several at once, ⌘-click connections (or choose Select to organize), then use Move to group… in the bar that appears. You can also drag connections onto a group, or onto the "Connections" heading to take them out.
  • Right-click a group to Rename group… or Delete group (its connections stay, one level up).
  • Pin to the top in a connection's menu keeps it first in every list.
  • Favorites: choose Add to favorites in a pane's … menu to add the folder it shows, or right-click a folder, a bucket, a drive root or a single-root server and choose Add to favorites. Favorites follow their folder when it's renamed or moved.

Where your passwords are kept

Passwords, secret keys and sign-in tokens are kept in an encrypted file on your device. Only the key to that file is in your system's keychain: the macOS Keychain, Windows Credential Manager, or the Secret Service on Linux. That means one keychain question at most, never a settings file with passwords in it. On Android the file is sealed by the Android Keystore. Connection details (server, user name, region) are stored separately, with no secrets.

Kybl Storage

No bucket of your own? Kybl Storage is S3 storage run by Kybl, with 10 GB free.

What you get

  • 10 GB free.
  • Stored in the EU, in Germany.
  • Encrypted at rest with AES-256, using a separate key for each bucket (SSE-C).
  • It's a normal S3 connection, so everything S3 can do in Kybl works, including share links.
  • It's the only connection where Kybl can make a New bucket for you.

Not end-to-end encrypted. Your files are encrypted on the storage servers, but the service handles the keys. If you need encryption only you can unlock, encrypt files before you upload them.

Connect Kybl Storage

  1. Click Connect Kybl Storage on the welcome card, or choose Kybl Storage in the New connection picker.
  2. Click Continue in browser. The Kybl account site opens.
  3. Sign in (or make an account) and approve this device. Kybl receives its own access key, named after your device. Nobody types or copies keys.

On another device? Choose Sign in on another device with a code. Kybl shows a QR code and a short code. Scan it with your phone, or open the link anywhere, and enter the code. A countdown shows how long the code works. If the browser doesn't open, click Use a code instead.

Then make a bucket with New bucket in the empty pane or the sidebar.

Keys and access

  • Each computer or phone gets its own key. You can see and revoke them on the account site's Access keys page.
  • If a key is revoked or the account deleted, the sidebar shows Sign in again. Connect again gives the device a fresh key.
  • Because files are encrypted, Kybl compares Kybl Storage files by size, not by checksum, when it verifies transfers.

Browsing

Open a connection from the sidebar, pick a bucket or place, and you're in. Everything here works the same on every connection.

Moving around

  • Open a folder: double-click it, or select it and press ↵ or ⌘O. In list view, the .. row at the top goes up.
  • Go up one level: ⌘↑, Backspace, or click the enclosing folder in the path. At the top of an archive, ⌘↑ goes back to the folder the archive is in, with the archive selected.
  • Back and forward: ⌘[ and ⌘], or your mouse's side buttons. Each pane remembers its last 100 places. (There are no back and forward buttons in the toolbar.)
  • Go to the connection's top: click the connection name in the toolbar. On a connection with buckets or places (S3, This computer, Google Drive, OneDrive) it lists them; on a server with one root it opens that root's top. Inside an archive it takes you out to the connection the archive is on.
  • Switch connection or bucket in this pane: click the connection badge before the path. It lists every connection with its buckets.

Breadcrumbs and Go to folder

The path reads the same everywhere: the connection, then its bucket, drive or place (a server with one root skips this step), then the folders down to the one you're in. An archive continues the path it's in, like This Mac › Downloads › site-backup.zip › site-backup. Every step is clickable. When the pane is too narrow, the folders nearest the top fold into … one at a time; click … to pick one of them. Right-click or ⌘-click the path for every step. You can drop files on any step of the place you're in.

To type a path, click the current folder's name, or press ⇧⌘G or ⌘L. The path turns into a text field. Type and press ↵ (Esc cancels). It accepts:

  • a path inside the current bucket or root;
  • on S3, bucket/path or s3://bucket/path;
  • on This computer, a full path;
  • a file's path: Kybl opens its folder and selects the file.

List and grid

The buttons at the right end of the pane's status bar switch the view:

  • As list shows columns. Right-click the column header to pick them: Size, Modified, Created, Kind, Type, Storage class (S3), ETag, and Permissions and Owner where the server has them. Drag a column edge to resize; double-click to reset.
  • As grid shows tiles with thumbnails. Bigger Icons (⌘+) and Smaller Icons (⌘−) in the View menu or the command palette resize them.
  • Compact layout (the third button) makes rows and tiles tighter.

View, sort, compact and hidden files are remembered for each pane separately.

Thumbnails and photos

The grid shows thumbnails for JPEG, PNG, GIF, WebP, BMP, TIFF and (on Apple systems) HEIC images. The Photos setting in Settings → Browsing decides how much Kybl fetches:

  • Off (the default on a new install): file icons only.
  • Placeholders: a blurry preview where one is known; nothing is downloaded.
  • Thumbnails: the blurry preview at once, then the real thumbnail.

Right-click a connection in the sidebar, or open its settings, to give it its own Photos in lists mode. You can also turn on Share placeholders with other devices (not on This computer): Kybl writes a small hidden file in each photo folder so your other devices show previews instantly.

Sorting

Click a column header, or use the Sort and group button in the toolbar to sort by Name, Date modified, Date created, Size, Kind or Type, ascending or descending. The same menu has Group by. Folders come first unless you turn that off in Settings. Sorting a very large folder by size or date loads all of it first.

Hidden files

On This computer, dot-files are hidden. Press ⇧⌘. (or choose Show hidden files in the Sort and group menu, or in the right-click menu on empty space) to show them in that pane. Other connections always show everything.

Search and filter

  1. Press ⌘F or click Filter or search in the pane's toolbar.
  2. Type. The folder filters by name as you type.
  3. Press ↵ to search all subfolders too. Results stream in as Kybl looks; Stop ends the search.

In the results, right-click an item and choose Show in folder to jump to it. Most actions still work on results. Esc or Clear search takes you back.

Search inside files. On This computer and SFTP servers, switch the search to Contents to find text inside files. Options: case sensitive, regular expression. Each result shows its first matching line, and Quick Look opens at that line. The command palette has Search Inside Files too.

Favorites and recent places

Open the pane's … menu and choose Add to favorites to put the folder it shows under Favorites in the sidebar; the same menu then offers Remove from favorites. You can also right-click a folder, a bucket, a drive root or a single-root server and choose Add to favorites. Recent places are in the command palette, and a new, empty pane lists your recent connections.

Folder info panel and git

Click the icon at the right end of a pane's status bar to open a small panel about the folder on screen: the connection (server, bucket, region or account), the path with a copy button, item count and size, and, where the drive reports it, the space used.

For a folder on This computer inside a git repository, Kybl shows the branch next to the path and marks changed files (M modified, A added, D deleted, R renamed, U untracked and so on). The info panel adds how far you are ahead or behind, counts of changed and staged files, the first few changed files, and the last commit.

Very large folders

Big S3 folders load in pages. The status bar says when only the first part is loaded ("More load as you scroll") and how many items have arrived so far.

Selecting files

With the mouse

  • Click to select one item. ⌘-click adds or removes one. ⇧-click selects a range.
  • Drag on empty space to draw a selection box. Hold ⇧ to add, ⌘ to toggle. The list scrolls by itself near its edges.
  • Click empty space to clear the selection.

Previewing and file info

Quick Look

Select a file and press Space for a large preview over the list. Press Space or Esc to close it, and the arrow keys to step through the folder. With several panes open, F3 works too.

What Quick Look shows:

  • Images: JPEG, PNG, GIF, WebP, AVIF, SVG, BMP, ICO, and HEIC on Apple systems. Other formats (TIFF, RAW) show their thumbnail.

Editing files

You can edit text files right inside Kybl, or open any file in your own app and let Kybl upload each save.

The built-in editor

On a server or in the cloud, Open (↵ or double-click) on a text, code, JSON, Markdown or CSV file shows it in Kybl's editor, full-window, and Save uploads it back. On This computer, right-click the file and choose Edit in Kybl. The Edit… button in the info column (Get Info) has it too, on every connection. Files up to 5 MB.

  1. The first time, Kybl asks When you save this file: choose Upload changes automatically, or Upload only if the file on the server hasn't changed since you opened it (recommended). Your last answer is preselected.
  2. Edit. A dot shows unsaved changes.
  3. Press ⌘S to save (or ⇧⌘S to save a copy). ⌘F finds and replaces. Esc or ⌘W closes, asking about unsaved changes.

If someone changed the file on the server meanwhile, Kybl offers Reload, Overwrite or Save as copy. Markdown has Edit, Split and Preview layouts; JSON can be checked and tidied; CSV can be edited as a table or as text.

Edit in your own app

For a file on a server or in the cloud, right-click it and choose Edit (⌘E) for its default app, or Edit with ▸ to pick one. This is in the computer app only, for files up to 100 MB.

  1. Answer the same When you save this file: question.
  2. Kybl downloads a private copy and opens it in the app.
  3. Every time you save in that app, Kybl uploads the file. A toast confirms each upload.

The Activity panel shows an Editing chip with each file you're editing and its state (waiting for a save, uploading, uploaded, changed on the server, or failed). From there you can open the file again, show the local copy, or Stop editing, which deletes the local copy (and asks first if changes haven't been sent).

If the server's copy changed while you edited, Kybl shows both versions with Compare and lets you choose: Overwrite the server's copy, Keep both (yours is uploaded as "name (edited).ext"), Discard my changes and reload the server's, or Stop editing and discard my changes.

Files on This computer open and save in place, so they don't need Edit. Google Docs, Sheets and Slides are edited in Google Drive, not here.

Make a new file

Press ⌥⌘N, or choose New file… from the Upload or create button or the right-click menu on empty space. Type a name (it starts as "untitled.txt") and click Create. Kybl makes an empty file and selects it, ready to edit. It never replaces a file that's already there.

The right-click menu

New folder

Press ⇧⌘N (or F7 with several panes open), or choose New folder… from the Upload or create button or the right-click menu. Type a name and press ↵. Kybl selects the new folder.

Copy, cut and paste

  • ⌘C copies and ⌘X cuts the selected items. Their paths also go on the clipboard as text, so you can paste them into a chat or a terminal.
  • ⌘V pastes into the folder on screen. To paste into a folder in the list, right-click it and choose Paste into "folder".
  • Paste works across connections too. Between two clouds or servers, it starts a background copy job (you confirm the destination first). Between This computer and a connection, files are uploaded or downloaded and the originals always stay, so a cut becomes a copy there.
  • Pasting a copy into the folder it came from makes "name (1).ext".

Duplicate

⌘D copies each selected item next to itself as "name copy.ext" (then "name copy 2.ext"), and selects the copy.

Rename and batch rename

Select one item and press F2 (or choose Rename…). Type the new name and press ↵. Kybl won't let you use a name that's taken, except that renaming a file over another asks Replace…?

S3, Azure and Google Cloud Storage have no real folders, so renaming a folder there copies every file inside. Big renames run as a job in the Activity panel.

Select several items and press F2 to open Batch rename:

  • Pattern builds names from pieces: {name} (the old name), {n} or {n:3} (a counter, padded to 3 digits), {date} or {date:YYYY-MM-DD} (modified date), {ext}, {size} and {folder}. Set the counter's start, step and order.
  • Find and replace changes part of each name, with optional regular expressions and match case.
  • Both can change the case (lowercase, UPPERCASE, Title Case) and the extension (lowercase, UPPERCASE, change or remove).

The preview shows every new name and flags problems (empty, too long, duplicate, already taken). Nothing runs until all are fixed, and batch rename never overwrites anything. One ⌘Z undoes the whole batch.

Delete and the Trash

Select items and press Delete (⌦ on a Mac) or ⌘⌫ (or F8 with several panes), or choose Delete….

  • On This computer, Google Drive, OneDrive and Dropbox the item reads Move to Trash (Recycle Bin on Windows). You can restore from the system Trash or the drive's own trash.
  • Everywhere else (S3, Azure, GCS, SFTP, FTP, WebDAV), deleting is permanent, and the confirmation says so.
  • Folders go with everything inside. Deleting a symbolic link removes only the link.
  • Turn off the question with Confirm before deleting in Settings → General.

Delete can't be undone with ⌘Z. Only the Trash on connections that have one can bring files back.

Undo

⌘Z, or Undo in the toast, reverses your last move, copy, duplicate or rename, up to 20 steps back. Undoing a copy deletes exactly what the copy made. Undo isn't offered when a move or copy replaced something.

When names clash

Before uploading, moving, copying, pasting or extracting, Kybl checks the destination. For each name that already exists it asks:

  • Replace the file, or Merge a folder (everything goes into the existing folder; same-named files inside are replaced);
  • Skip it;
  • Keep both: the new one gets a number, "name (1).ext".

Tick Do this for the other N to answer the rest at once. Closing the dialog cancels the whole action. Background copy jobs have their own choices; see Copy / Move options.

Move to the parent folder

Right-click and choose Move to "parent" to move the selection up one level.

Upload and download

  • Upload files (⌘U) or Upload folder (⇧⌘U) from the Upload or create button. Folders keep their structure. You can also drag files in from Finder or Explorer.
  • Download (⇧⌘D): one file opens a Save dialog; several items or folders ask for a folder. Folders start downloading straight away while Kybl is still finding their files.
  • Turn off Ask where to save downloads in Settings to send everything straight to your Downloads folder. A file that's already there is kept and the new one gets a number.
  • Google Docs, Sheets and Slides download as Office files or PDF (Download as…).
  • There's no Download on This computer; copy the files instead.

Copy path and S3 URI

Copy path puts the item's full path on the clipboard (one line per item). On S3 connections it's Copy S3 URI instead (s3://bucket/key). Right-click empty space to copy the path of the folder on screen.

Permissions and links on servers

  • Permissions… (SFTP and FTP): tick Read, Write and Execute for Owner, Group and Others, or type the octal number. For folders, Apply to enclosed items sets everything, files only or folders only.
  • Show original (SFTP): for a symbolic link, jumps to the folder of what it points to and selects it.
  • Make link… (SFTP): makes a symbolic link next to the item.

Drag and drop

Inside Kybl

  • Drag items onto a folder, a breadcrumb, another pane, a bucket in the sidebar, a workspace tab or a terminal.
  • A drop moves. Hold ⌥ (at any time during the drag) to copy instead. The label next to the pointer says which: "Move to X · ⌥ to copy" or "Copy to X".
  • Rest over a folder for a moment and it springs open, so you can go deeper.
  • Between two different connections, or between This computer and a connection, the drop always copies (the originals stay). Between clouds it runs as a background job after a quick confirm.
  • Dropping on a workspace tab puts the items in that workspace's active pane, with a Show button in the toast. Rest on the tab to open it and drop into any of its panes. Rest on + to open a new workspace.
  • Dropping on a terminal types the items' paths into the shell.

From Finder or Explorer into Kybl

Drop files and folders from your desktop onto a pane to upload them there. An overlay says "Drop to upload to …". Name clashes go through the conflict dialog.

From Kybl to other apps

Drag items out of the window into Finder, Explorer, a mail or a chat app. Files on This computer (and in synced folders) go as real files. Small files from other connections (up to 64 MB each, 20 files and 256 MB in all) are fetched as you drag, so chat and mail apps accept them. On macOS, anything bigger downloads to wherever the receiving app asks; on Windows and Linux such items stay behind.

Rearranging panes

Drag a pane by the empty part of its toolbar. Over another pane, drop on an edge to dock it there, or in the middle to swap the two. Esc cancels.

Copy and move between connections

Kybl copies straight from one connection to another: a bucket to a server, Dropbox to S3, a server to another server. It picks the fastest route and keeps going after a restart.

Copy to ▸ and Move to ▸

The right-click menu has Copy to ▸ and Move to ▸. Each lists the folders of your other open panes (when there are several), then recent places and favorites, and ends with Choose folder…. Pick one and the selection goes there.

Choose folder… opens a folder picker with every connection. Get Info and Quick Look have a Move or copy to… button that opens the same picker.

With exactly two panes, F5 copies and F6 moves the selection to the other pane's folder. With more panes they show the same list as Copy to ▸.

The Copy / Move to… dialog

To copy or move a whole folder, a bucket or an entire connection to somewhere else, use Copy / Move to…. You'll find it in:

Workspaces

Workspaces are tabs along the top of the window. Each one keeps its own layout of panes, so you can have one for a client's servers, one for photos and one for a deploy.

Terminal

SSH tunnels

An SFTP connection can forward local ports to its server, for example to reach a database that only listens inside the server.

  1. Edit the SFTP connection and open the Tunnels section.
  2. Add a tunnel: the Local port on your computer, the Remote host as the server sees it (such as localhost or db.internal) and the Remote port. Give it a name if you like.
  3. Switch on Auto-start to start it the first time Kybl opens that connection.

Archives (zip and tar)

Compress

Select items in one folder, right-click and choose Compress “name” (or Compress N items for several). Kybl makes a .zip named after the item (or "Archive.zip"). Photos, video, music and other already-compressed files are stored as they are, so it's quick.

Extract

  • Extract here puts a folder named after the archive next to it. Works for .zip, .tar, .tar.gz and .tgz.
  • Extract to… lets you pick any folder, on any connection.

On SFTP servers that have zip, unzip or tar, Kybl packs and unpacks on the server itself. Elsewhere it does the work on your computer and uploads the result. Each one is a single row in the Activity panel that you can stop.

Open an archive like a folder

Double-click an archive (or press ↵) to look inside without extracting. You can preview, copy out or extract items. It's read-only, so menu items that would change it are left out. Going up from the top returns to the folder that holds the archive.

Compare

Compare two files

Select two text files and right-click: Compare files. Or select one file here and one in another pane: Compare with "other file". The older file goes on the left.

The toolbar switches between side by side and inline, wraps lines, ignores whitespace, and steps through changes. Press F7 or n for the next change, ⇧F7 or p for the previous, Esc to close.

Compare two folders

Open the two folders in two panes, then choose Compare with in the pane's … menu (or Compare Folders in the command palette).

Kybl lists what's only on one side, what's newer on one side, what differs, and how many match. Changed text files have a Compare button. It also selects what the other side is missing, so pressing F5 copies it across. Files are compared by size, date and, between two S3 buckets (not Kybl Storage), checksum. Transfers and activity

Every upload, download, copy job and long operation shows in the Activity panel at the bottom of the window.

The Activity panel

It opens by itself when a transfer starts (turn that off with Show activity automatically in Settings), or choose Show activity from the pane's … menu. Its tabs:

  • In progress: running, queued and paused transfers, plus running sync and jobs. Each row shows speed, time left and bytes.
  • Failed: what went wrong, in plain words, with Retry.
  • Done: finished items and what was checked. Clear finished empties it.
  • Log: a readable history of what happened (see below).
  • Jobs: copies and moves between connections, and mirrors.

Pause, resume, cancel and retry

  • On each row: pause, resume, cancel, retry, move to the top of the queue, open, or show in Finder, Explorer or Files.
  • In the panel header: Pause all, Resume all, Cancel transfers, Retry failed, Clear finished and Clear failed. Which of them show depends on the tab.
  • Each connection has its own queue, so a long upload to one never holds up a download from another.

Resume after a restart

If Kybl quits or crashes mid-transfer, unfinished transfers come back paused next time. Resume them and they carry on from where they stopped, where the connection allows it: partial downloads, S3 multipart uploads, cloud-drive upload sessions and temporary files on SFTP and FTP servers. A dropped connection resumes the download from the same version of the file. Leftovers nobody resumes are cleaned up after 7 days.

Azure, Google Cloud Storage and WebDAV uploads start again from the beginning after a restart.

Speed limits and how many at once

  • Click the gauge in the Activity panel to set a limit: No limit, 1, 5 or 10 MB/s, or Custom. It applies to running transfers immediately.
  • Settings → Transfers and sharing has separate Download limit and Upload limit (Unlimited, 1, 5, 10, 25 or 50 MB/s, or Custom), Files at the same time per connection (1 to 8, default 3) and Parts per file for big files (1 to 8, default 4).
  • Limits are shared by all transfers in that direction and also apply to copy jobs.

Verify after transfer

Verify files after copying in Settings → Transfers and sharing:

  • Off (default): trust the server's answer.
  • Size: compare sizes. A mismatch fails the transfer, with Retry.
  • Checksum: compare a content fingerprint where both sides have one (S3, Google Drive, Dropbox, OneDrive, SFTP), otherwise size. The Done tab shows what was checked.

Encrypted storage (including Kybl Storage), FTP, WebDAV and This computer are checked by size.

The log

The Log tab says in plain words what you started and how it ended: "Started downloading 'photos' (folder) from X to Downloads", then counts, size and time, or why it failed, with the first errors under Details. It also records connecting ("Connected to X (1.4 s)") and errors. Filter it to problems only, or click Copy to paste the whole log into a bug report.

On phones

Phones have a Transfers screen with the same actions. Android keeps transfers going in the background with a progress notification (with Cancel), even if you swipe the app away. iPhone keeps going for about half a minute after you leave the app, then resumes the rest when you come back. Wi-Fi only makes transfers wait for Wi-Fi. See The phone app.

Keeps a copy of the remote folder on your computer, checked on a schedule. The remote folder is the original.
Two-way
Changes on either side are copied to the other. Renames stay renames. Edited on both sides? You keep both versions.

Options

  • Mirror deletions (one-way only, off by default): deleting a file on one side deletes it on the other. With it off, an upload sync keeps everything you ever uploaded, which makes it a simple backup. In download mode, local files go to the Trash, and files you edited locally are never removed. Two-way sync always passes deletions on, behind the guard below.
  • Keep deleted files in a trash folder: for connections without their own trash, deleted files go to a dated .kybl-trash folder in the remote folder. On by default for two-way.
  • Ask before big deletions (on by default): if a sync would delete more than 50 files and more than a fifth of the folder, it stops and asks. A side that suddenly looks empty is always checked with you.
  • Full check every 1 minute, 5 minutes (default), 15 minutes or 1 hour (in download mode it's called Check for changes every). Local changes go over right away; this is how often the other side is looked at, since most storage can't announce changes.
  • Ignore: patterns to skip, one per line, like a .gitignore. The defaults skip .DS_Store, Thumbs.db, desktop.ini, temporary files, .git/ and node_modules/. Reset to defaults brings them back.

Deletions waiting

When the guard stops a sync, the folder shows Deletions waiting. Look through the list (Show files), then click Delete them or Keep the files. Nothing is deleted until you decide. The tray menu shows Confirm deletions in N folders… while something waits.

Conflicts

If a file changed on both sides, Kybl keeps both: the other side's version keeps the name and yours becomes a copy next to it. The folder lists its Conflicts, each with:

  • Open both to look at the two versions;
  • Keep mine: your version replaces the other one, on both sides;
  • Keep theirs: your copy goes to the Trash;
  • Keep both: both files stay and the conflict stops showing.

Kyblík in the menu bar

The little bucket in the menu bar (macOS) or system tray (Windows, Linux) shows how your folders are doing: all synced, syncing, paused, or in need of a hand. Its menu shows a status line ("Syncing… 14 of 18 files", "Up to date · 3 folders"), and has Open Kybl, Sync now, Pause syncing, Sync settings…, your drives, Check for updates… and Quit Kybl. Review N conflicts… and Confirm deletions… appear when something waits for you. The folder-sync indicator at the bottom of the sidebar shows the same status.

Syncing with the window closed

Sync keeps running when you close the window, as long as Keep running in the menu bar is on. Turn on Open at login in Settings → General and Kybl starts quietly at login, so synced folders stay current.

Pause, sync now, stop

Each synced folder in Settings → Folder sync has Sync now, Pause / Resume, edit and remove (files stay where they are). Pause syncing pauses all of them. Each shows its state (Up to date, Checking, Syncing, Problem, Paused or Waiting for you), the file it's on, progress, and the last sync time.

Keep & sync and jobs

The Keep & sync ▸ submenu, on a folder's right-click menu and in the pane's … menu, gathers the ways to keep a folder somewhere else. Everything it starts shows in the Activity panel.

What's in Keep & sync

  • Sync this folder…: set up folder sync with this folder.
  • Keep on this device: makes a two-way synced copy in a Kybl folder in your home folder and opens it in Finder or Explorer. The first time, Kybl explains that deleting files there deletes them online too. Once kept, the item reads Kept on this device; click it to stop (the copy stays on disk).
  • Mount as drive…: see Drives.
  • Copy / Move to… (in the pane's … menu and the empty-space menu, for the folder on screen): copy or move it, or a whole bucket, to another connection. See the Copy / Move to dialog.
  • Mirror to… and your saved mirrors (Run "name"). See Mirror.

Sync, Keep on this device and Mount as drive aren't offered for folders on This computer, since those files are already on your disk. Inside an archive, Keep & sync only offers what doesn't change the archive.

The Jobs tab

Copies and moves between connections and mirrors run as jobs. A job goes through: getting ready, copying (or moving, or removing originals), and done. It can also be paused, waiting for Wi-Fi (phones), waiting for you to sign in again, done with problems, or stopped. Use Pause, Resume, Stop, Show where it went and Remove from the list. Failed files have Try again.

Jobs are saved as they run, so they continue after a quit, a crash or a phone closing the app.

Jobs run when you start them; there's no timetable for running them later. For something that keeps running by itself, use folder sync. To repeat the same copy, save it as a mirror and run it again in one click.

Mirror

Mirror makes one folder match another, once: deploy a website to a server, or pull a folder down. It shows you exactly what it will do before it touches anything.

Mirror a folder

  1. Right-click a folder and choose Keep & sync ▸ Mirror to…. The Mirror sheet opens with that folder as From.
  2. Pick the To folder, on any connection. The swap button between them copies the other way instead.
  3. Open Options if you need them (below).
  4. Click Check. Kybl lists both sides and compares them, without changing anything.
  5. Look at the result tabs: Copy (new and changed files), Delete (only when deleting is on) and Same (files already up to date). Each is grouped by folder.
  6. Click Mirror N files (or Mirror and delete N). The job copies first and deletes last, and touches nothing outside the list you saw.

Options

Delete what isn't in the source
Off by default. When on, files only at the destination are deleted, so it matches exactly. Deletions on This computer go to the Trash.
Copy a file when
Size or date differs (default, quick, works everywhere), Size differs, or Checksum differs (exact but slower, only where both connections have checksums). Kybl allows for clocks that round to the minute, as FTP servers do.
Leave out
Patterns of files never copied or deleted, one per line, like a .gitignore. By default .git/, node_modules/, .DS_Store, Thumbs.db and .env.
Also leave out what .gitignore lists
Skips whatever the source folder's .gitignore lists, handy for deploying a project.

Links are left alone: nothing at or behind a link is copied or deleted. If the destination folder doesn't exist yet, it's made first.

Save and re-run a mirror

  • Name a mirror to keep it ("Keep it, to run again with one click"). The Saved menu in the sheet loads, renames or forgets saved mirrors; New mirror starts fresh.
  • Run a saved mirror from the folder's Keep & sync ▸ Run "name", or from the command palette (Run mirror "name").
  • A saved mirror checks first. If it would delete anything, the sheet opens so you can confirm.

  2. Give it a Name and a Command, using placeholders for the files (below). The preview shows what would run.

Troubleshooting

When something fails, Kybl says why in plain words and usually offers the fix right there, often with Try again. Here are the common ones.

"Couldn't connect" or "Can't reach the storage server"

  • Check your internet connection, and your VPN if the server needs one.
  • Edit the connection and check the endpoint or server address and port. "Nothing is answering at that address" means the address is wrong or the server is down.
  • Click Try again. Kybl drops the old connection first, so it really reconnects.

"Access denied"

  • The key isn't allowed to do that. Check its permissions with your provider.
  • A brand-new key can take a few minutes to start working at some providers (such as Hetzner). Wait and try again.
  • If your key can't list buckets, that's not a failed connection: use Open bucket by name, or set Bucket in the connection.

"Doesn't recognise the access key" or "secret key doesn't match"

Edit the connection and enter the keys again. Copying from a web page sometimes picks up the wrong characters; Kybl trims spaces and line breaks for you. If the credentials have expired, create fresh ones.

"This bucket lives in another region"

Edit the connection and set the bucket's region, and check the endpoint matches it. Picking the provider preset again fills in the right endpoint.

"Your computer's clock is off"

S3 servers refuse requests from a clock that's too far wrong. Turn on setting the time automatically in your system settings, then try again.

Certificate, host key or plain-FTP questions

  • Trust this certificate…: the server uses its own certificate. Check the details, and trust it only if you expect it. See Certificates.
  • Trust this server? on SFTP: normal the first time. If Kybl says the server's key changed, find out why before you accept it.
  • Connect without encryption on FTP: the server doesn't offer encryption. Your password would travel readable.

"Sign in again"

Google Drive, OneDrive, Dropbox or Kybl Storage stopped letting Kybl in (you changed your password or revoked access). Right-click the connection and choose Sign in again. Use the same account; your synced folders and jobs carry on afterwards.

Keychain or keyring prompts

  • On macOS, Kybl asks the Keychain once for the key to its encrypted store. Choose Always Allow so it doesn't ask again.
  • On Linux, if Kybl can't save secrets, install and unlock a Secret Service such as GNOME Keyring or KWallet.
  • On Android, removing the phone's screen lock or restoring a backup to another phone can lose the key; Kybl tells you, and you'll need to enter your passwords again.

macOS won't open it, or Windows SmartScreen warns

  • macOS: System Settings → Privacy & Security → Open Anyway. You only need to do this once.
  • Windows: in the SmartScreen warning, click More info → Run anyway.
  • iPhone: if Kybl stops opening after 7 days, refresh it in AltStore or SideStore.

Other messages

"The server is busy and asked to slow down"
Wait a moment and try again, or lower Files at the same time.
"The storage is full, or over its quota"
Free up space or raise your plan with the provider.
"This file isn't there any more"
Someone moved or deleted it. Refresh with ⌘R.
"That place is outside the folders Kybl can open here"
On phones, Kybl can only reach folders you've given it.
"Drives aren't available on Windows yet"
Drives work on macOS and Linux for now. Use folder sync or Keep on this device instead.
